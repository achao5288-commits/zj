# 居家健康监测 & 穿戴设备接入模块 - 完整实现说明

## 一、模块概述

本模块实现了居家健康监测和穿戴设备接入的完整功能,包括:
1. **设备管理**: 对接智能手环、血压计、血糖仪、体脂秤等家用医疗设备
2. **健康监测**: 自动同步生理数据,实时监测生命体征
3. **健康打卡**: 每日健康打卡,记录身体状况
4. **异常预警**: 异常数据实时预警,双向提醒(居民+医生)

## 二、数据库设计

- `HealthMonitoringController.java` - 健康监测API
  - `GET /healthMonitoring/queryByPage` - 分页查询监测数据
  - `POST /healthMonitoring/add` - 添加监测数据
  - `GET /healthMonitoring/statistics/type` - 按类型统计
  - `GET /healthMonitoring/statistics/date` - 按日期统计

- `HealthCheckinController.java` - 健康打卡API
  - `GET /healthCheckin/queryByPage` - 分页查询打卡记录
  - `GET /healthCheckin/today` - 查询今日打卡
  - `POST /healthCheckin/add` - 添加/更新打卡

- `HealthAlertController.java` - 健康预警API
  - `GET /healthAlert/queryByPage` - 分页查询预警
  - `GET /healthAlert/unread/count` - 未读预警数量
  - `GET /healthAlert/unread` - 未读预警列表
  - `POST /healthAlert/markAsRead/{alertId}` - 标记已读
  - `POST /healthAlert/handle` - 处理预警

## 五、使用流程

### 5.1 部署步骤

1. **导入数据库表**
```bash
mysql -u root -p spb_yd < src/main/resources/health_monitoring_setup.sql
```

2. **启动项目**
```bash
mvn spring-boot:run
```

3. **访问系统**
- 主页: http://localhost:8080/spbYq/index.html
- 通过主页进入"居家健康监测"模块

### 5.2 用户使用流程

1. **绑定设备**
   - 进入设备管理页面
   - 点击"添加设备"
   - 选择设备类型(手环/血压计/血糖仪/体脂秤)
   - 填写设备信息并保存

2. **查看监测数据**
   - 系统自动同步设备数据(需设备SDK支持)
   - 或手动录入监测数据
   - 查看数据趋势图表

3. **每日打卡**
   - 进入健康打卡页面
   - 填写今日身体状况
   - 提交打卡记录

4. **处理预警**
   - 查看预警列表
   - 点击预警查看详情
   - 标记已读或处理预警

## 七、异常数据预警规则

系统内置以下预警规则(可在Service层扩展):

### 7.1 血压预警
- **正常**: 收缩压 90-140 mmHg, 舒张压 60-90 mmHg
- **偏高**: 收缩压 140-160 或 舒张压 90-100
- **高危**: 收缩压 >160 或 舒张压 >100

### 7.2 血糖预警
- **正常空腹**: 3.9-6.1 mmol/L
- **偏高**: 6.1-7.0 mmol/L
- **高危**: >7.0 mmol/L

### 7.3 心率预警
- **正常**: 60-100 bpm
- **偏低**: <60 bpm
- **偏高**: >100 bpm

### 7.4 体温预警
- **正常**: 36.1-37.2°C
- **低烧**: 37.3-38.0°C
- **高烧**: >38.0°C

## 十、注意事项

1. **权限控制**: 普通用户只能查看/管理自己的数据,root用户可管理所有数据
2. **数据安全**: 健康数据属于敏感信息,需做好加密和访问控制
3. **设备兼容性**: 不同品牌设备API不同,需单独适配
4. **实时性**: 建议使用WebSocket实现实时数据推送和预警通知
5. **性能优化**: 监测数据量大时需做好分页和索引优化
