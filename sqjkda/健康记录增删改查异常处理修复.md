# 健康记录增删改查异常处理修复

## 🔍 问题描述

```
POST http://localhost:8081/spbYq/healthRecords/deleteById/1268 500 (Internal Server Error)
```

所有增删改操作在出现错误时都返回500错误，没有具体的错误信息。

## 🔍 问题原因

### 原始代码问题

**没有异常处理**：
```java
@RequestMapping("deleteById/{id}")
public ReturnVO deleteById(HttpServletRequest request, @PathVariable("id") Integer id) {
    if (!isRootUser(request)) {  // ❌ 如果Session为空，这里会抛异常
        return vo;
    }
    if (!this.healthRecordsService.deleteById(id)) {  // ❌ 如果数据库异常，直接500
        return returnVO;
    }
    returnVO.setCode(1);
    return returnVO;
}
```

**问题**：
1. ❌ 没有try-catch，任何异常都会导致500错误
2. ❌ 没有检查Session是否为空
3. ❌ 没有检查参数是否有效
4. ❌ 错误信息不明确，无法调试

## ✅ 修复内容

### 1. 删除方法 (deleteById)

**修复前**：
```java
@RequestMapping("deleteById/{id}")
public ReturnVO deleteById(HttpServletRequest request, @PathVariable("id") Integer id) {
    if (!isRootUser(request)) {
        ReturnVO vo = ReturnVO.getNodataFoundReturnVO();
        vo.setCode(0);
        vo.setMsg("无权限操作");
        return vo;
    }
    ReturnVO returnVO = ReturnVO.getNodataFoundReturnVO();
    if (!this.healthRecordsService.deleteById(id)) {
        return returnVO;
    }
    returnVO.setCode(1);
    returnVO.setMsg("删除成功");
    return returnVO;
}
```

**修复后**：
```java
@RequestMapping("deleteById/{id}")
public ReturnVO deleteById(HttpServletRequest request, @PathVariable("id") Integer id) {
    try {
        // ✅ 检查登录状态
        Object userTypeObj = request.getSession().getAttribute("userType");
        if (userTypeObj == null) {
            ReturnVO vo = ReturnVO.getNodataFoundReturnVO();
            vo.setCode(0);
            vo.setMsg("请先登录");
            return vo;
        }
        
        // ✅ 权限检查
        if (!isRootUser(request)) {
            ReturnVO vo = ReturnVO.getNodataFoundReturnVO();
            vo.setCode(0);
            vo.setMsg("无权限操作，需要root权限");
            return vo;
        }
        
        // ✅ 检查id是否有效
        if (id == null) {
            ReturnVO vo = ReturnVO.getNodataFoundReturnVO();
            vo.setCode(0);
            vo.setMsg("ID不能为空");
            return vo;
        }
        
        // ✅ 删除操作
        boolean result = this.healthRecordsService.deleteById(id);
        if (!result) {
            ReturnVO returnVO = ReturnVO.getNodataFoundReturnVO();
            returnVO.setCode(0);
            returnVO.setMsg("删除失败，记录可能不存在");
            return returnVO;
        }
        
        // ✅ 删除成功
        ReturnVO returnVO = ReturnVO.getNodataFoundReturnVO();
        returnVO.setCode(1);
        returnVO.setMsg("删除成功");
        return returnVO;
    } catch (Exception e) {
        // ✅ 捕获异常，返回友好错误信息
        e.printStackTrace();
        ReturnVO returnVO = ReturnVO.getNodataFoundReturnVO();
        returnVO.setCode(0);
        returnVO.setMsg("删除失败：" + e.getMessage());
        return returnVO;
    }
}
```

## 🔧 调试技巧

### 1. 查看后端控制台日志

当发生错误时，后端会打印详细的异常堆栈：

```
java.sql.SQLException: Cannot delete or update a parent row: a foreign key constraint fails
    at com.yq.spbYq.controller.HealthRecordsController.deleteById(HealthRecordsController.java:xxx)
```

### 2. 查看浏览器Network标签

1. 按F12打开开发者工具
2. 切换到Network标签
3. 执行操作
4. 点击请求查看：
   - **Request Headers** - 请求头（检查Cookie）
   - **Response** - 服务器返回的数据

### 3. 常见数据库错误

**外键约束错误**：
```
Cannot delete or update a parent row: a foreign key constraint fails
```
**原因**：该记录被其他表引用
**解决**：先删除关联记录，或修改数据库设计

**字段为空错误**：
```
Column 'report_date' cannot be null
```
**原因**：必填字段没有传值
**解决**：检查前端是否传递了所有必填字段

**字段长度超限**：
```
Data too long for column 'report_name'
```
**原因**：字段值超过数据库定义的长度
**解决**：缩短字段值或修改数据库字段长度
