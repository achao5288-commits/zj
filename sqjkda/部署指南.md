# 社区健康档案系统 - 部署指南

## 📋 系统要求

### 1. 软件环境

| 软件 | 版本要求 | 说明 |
|------|---------|------|
| **JDK** | 1.8 或以上 | Java 开发工具包 |
| **Maven** | 3.6+ | 项目构建工具 |
| **MySQL** | 8.0+ | 数据库服务器 |
| **操作系统** | Windows/Linux/Mac | 支持所有主流操作系统 |

### 2. 硬件要求

- **CPU**: 2核心以上
- **内存**: 4GB 以上（推荐 8GB）
- **硬盘**: 10GB 可用空间
- **网络**: 需要访问 DeepSeek API（AI健康分析功能）

## 🚀 部署步骤

### 第一步：安装必要软件

#### 1. 安装 JDK 1.8+

**Windows**:
```powershell
# 下载 JDK 1.8 或更高版本
# 推荐下载地址：https://www.oracle.com/java/technologies/downloads/

# 验证安装
java -version
```

**Linux (Ubuntu)**:
```bash
sudo apt update
sudo apt install openjdk-8-jdk
java -version
```

#### 2. 安装 Maven

**Windows**:
```powershell
# 1. 下载 Maven：https://maven.apache.org/download.cgi
# 2. 解压到 C:\apache-maven-3.8.x
# 3. 添加环境变量：
#    - MAVEN_HOME = C:\apache-maven-3.8.x
#    - PATH 中添加 %MAVEN_HOME%\bin

# 验证安装
mvn -version
```

**Linux**:
```bash
sudo apt install maven
mvn -version
```

#### 3. 安装 MySQL 8.0+

**Windows**:
```powershell
# 1. 下载 MySQL Installer：https://dev.mysql.com/downloads/installer/
# 2. 运行安装程序，选择 Server 版本
# 3. 设置 root 密码（请记住这个密码）
# 4. 默认端口：3306

# 验证安装
mysql --version
```

**Linux**:
```bash
sudo apt install mysql-server
sudo systemctl start mysql
sudo systemctl enable mysql
mysql --version
```

## 🔧 生产环境部署建议

### 1. 修改配置文件

创建 `application-prod.properties`：

```properties
# 生产环境配置
server.port=80
server.servlet.context-path=/

# 数据库配置（使用生产数据库）
spring.datasource.url=jdbc:mysql://生产服务器IP:3306/zhao?useUnicode=true&characterEncoding=utf8&useSSL=true&serverTimezone=Asia/Shanghai
spring.datasource.username=spbYq_user
spring.datasource.password=生产环境密码

# 关闭开发工具
spring.devtools.add-properties=false

# 日志级别调整为 WARN
logging.level.com.yq.spb_yd=WARN
logging.level.root=WARN

# 关闭 MyBatis SQL 日志输出
mybatis.configuration.log-impl=org.apache.ibatis.logging.nologging.NoLoggingImpl
```

### 2. 使用 HTTPS

生产环境强烈建议使用 HTTPS：

**方式1：使用 Nginx 反向代理**
```nginx
server {
    listen 443 ssl;
    server_name your-domain.com;
    
    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;
    
    location / {
        proxy_pass http://localhost:8081;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

# HTTP 重定向到 HTTPS
server {
    listen 80;
    server_name your-domain.com;
    return 301 https://$server_name$request_uri;
}
```

**方式2：Spring Boot 内置 SSL**
```properties
server.ssl.enabled=true
server.ssl.key-store=classpath:keystore.p12
server.ssl.key-store-password=your-password
server.ssl.key-store-type=PKCS12
server.ssl.key-alias=tomcat
```

### 3. 配置防火墙

```bash
# Linux (UFW)
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp
sudo ufw allow 3306/tcp  # 仅允许应用服务器访问

# Windows 防火墙
# 控制面板 -> Windows Defender 防火墙 -> 高级设置 -> 入站规则
# 添加端口 8081 的入站规则
```

### 4. 设置开机自启

**Linux (Systemd)**:
```bash
sudo nano /etc/systemd/system/spbyq.service
```

内容：
```ini
[Unit]
Description=Community Health Archive System
After=syslog.target network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/spbyq
ExecStart=/usr/bin/java -jar spb_yd-0.0.1-SNAPSHOT.war
SuccessExitStatus=143
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

启动服务：
```bash
sudo systemctl daemon-reload
sudo systemctl start spbyq
sudo systemctl enable spbyq
sudo systemctl status spbyq
```

**Windows (任务计划程序)**:
1. 打开"任务计划程序"
2. 创建基本任务
3. 触发器：计算机启动时
4. 操作：启动程序 `java -jar C:\path\to\spb_yd-0.0.1-SNAPSHOT.war`

## 🐛 常见问题排查

### 1. 启动失败：端口被占用

**错误信息**: `Port 8081 was already in use`

**解决方案**:
```bash
# Windows：查找占用端口的进程
netstat -ano | findstr :8081
taskkill /PID <进程ID> /F

# 或修改 application.properties 中的端口
server.port=8082
```

### 2. 数据库连接失败

**错误信息**: `Communications link failure`

**检查清单**:
- [ ] MySQL 服务是否启动？
- [ ] 数据库用户名密码是否正确？
- [ ] 数据库 `zhao` 是否存在？
- [ ] 防火墙是否放行 3306 端口？

**解决方案**:
```bash
# 检查 MySQL 状态
# Windows
Get-Service -Name MySQL*

# Linux
sudo systemctl status mysql

# 启动 MySQL
# Windows
net start MySQL80

# Linux
sudo systemctl start mysql
```

### 3. 找不到主类

**错误信息**: `Could not find or load main class`

**解决方案**:
```bash
# 重新编译打包
mvn clean package -DskipTests

# 检查 pom.xml 中的 packaging 是否为 war
# <packaging>war</packaging>
```

### 4. AI 健康分析功能不可用

**检查**:
```properties
# 确保 API Key 正确
deepseek.api.key=sk-your-actual-api-key

# 确保启用
deepseek.api.enabled=true
```

### 5. 静态资源 404

**解决方案**:
确保静态文件在正确的位置：
```
src/main/webapp/
├── index.html
├── login.html
├── css/
├── js/
└── images/
```
