### 2. 健康监测数据模块 📊

#### 已有功能
- ✅ 查看监测数据列表
- ✅ 异常数据标识
- ✅ 数据统计（总数显示）
- ✅ 自动同步设备数据

#### 数据结构
```javascript
{
  dataType: 'heart_rate',      // 数据类型
  dataValue: 75,               // 数值
  dataUnit: 'bpm',             // 单位
  measurementTime: '2024-xx-xx', // 测量时间
  isAbnormal: 0                // 是否异常（0正常/1异常）
}
```

#### 支持的数据类型
- ❤️ 心率 (heart_rate) - bpm
- 🩸 血压 (blood_pressure) - mmHg
- 🍬 血糖 (blood_glucose) - mmol/L
- ⚖️ 体重 (weight) - kg
- 🌡️ 体温 (temperature) - °C
- 💨 血氧 (oxygen/spo2) - %
- 🚶 步数 (steps) - 步

### API接口

#### 设备管理 `/healthDevice`
```
GET    /healthDevice/queryByPage      # 分页查询设备
POST   /healthDevice/add              # 添加设备
POST   /healthDevice/edit             # 编辑设备
POST   /healthDevice/deleteById/{id}  # 删除设备
```

#### SDK接入 `/deviceSdk`
```
GET    /deviceSdk/validate            # 验证SDK码
POST   /deviceSdk/addBySdk            # 通过SDK添加设备
POST   /deviceSdk/sync/{deviceId}     # 同步设备数据
```

#### 健康监测 `/healthMonitoring`
```
GET    /healthMonitoring/queryByPage        # 分页查询
POST   /healthMonitoring/add                # 添加数据
GET    /healthMonitoring/statistics/type    # 按类型统计
GET    /healthMonitoring/statistics/date    # 按日期统计
```

#### 健康打卡 `/healthCheckin`
```
GET    /healthCheckin/queryByPage    # 分页查询
GET    /healthCheckin/today          # 查询今日打卡
POST   /healthCheckin/add            # 添加/更新打卡
```

#### 预警通知 `/healthAlert`
```
GET    /healthAlert/queryByPage          # 分页查询
GET    /healthAlert/unread/count         # 未读数量
GET    /healthAlert/unread               # 未读列表
POST   /healthAlert/markAsRead/{id}      # 标记已读
POST   /healthAlert/handle               # 处理预警
```

## 🆘 常见问题

### Q1: 添加设备后看不到？
**A:** 刷新页面，检查控制台是否有错误

### Q2: 数据同步失败？
**A:** 检查设备状态是否为"在线"

### Q3: 打卡提示重复？
**A:** 每天只能打卡一次，次日可再次打卡

### Q4: 预警不显示？
**A:** 需要异常数据才会触发预警
