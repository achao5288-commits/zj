# 设备添加功能调试指南

## 问题：点击"验证并添加"按钮后没有反应

### 可能的原因和解决方案

#### 1️⃣ **浏览器控制台有错误**

**排查步骤：**
1. 按 `F12` 打开浏览器开发者工具
2. 切换到 "Console"（控制台）标签
3. 点击"验证并添加"按钮
4. 查看是否有红色错误信息

**常见错误：**
- `bootstrap is not defined` - Bootstrap JS 未加载
- `$ is not defined` - jQuery 未加载
- `网络错误` - 后端服务未启动

---

#### 2️⃣ **SDK码格式不正确**

**正确的SDK码格式：**
```
小米手环：MI-BAND-SDK-2024
欧姆龙血压计：OMRON-BP-SDK-2024
罗氏血糖仪：ROCHE-GLU-SDK-2024
华为体脂秤：HUAWEI-SCALE-SDK-2024
```

**注意：**
- 不区分大小写（`mi-band-sdk-2024` 也可以）
- 最后必须是4位数字
- 不能有空格或其他字符

---

#### 3️⃣ **设备名称未填写**

现在系统会检查设备名称是否为空，如果为空会提示"请输入设备名称"。

---

#### 4️⃣ **后端服务未启动**

**检查步骤：**
1. 确认Spring Boot项目正在运行
2. 访问 `http://localhost:8080/spbYq/` 确认服务正常
3. 查看控制台是否有错误信息

**启动命令：**
```bash
mvn spring-boot:run
```

---

#### 5️⃣ **用户未登录**

**检查步骤：**
1. 确认已经登录系统
2. 页面右上角应显示用户名
3. 如果显示"未登录"，请先登录

**登录地址：**
```
http://localhost:8080/spbYq/login.html
```

---

#### 6️⃣ **Session丢失**

**症状：**
- 已登录但请求返回"请先登录"
- 刷新页面后需要重新登录

**解决方案：**
参考项目中的 `Session丢失问题修复说明.md`

---

### 🔍 调试步骤

#### 步骤1：打开浏览器控制台

按 `F12` 打开开发者工具，切换到 Console 标签。

#### 步骤2：点击"验证并添加"

观察控制台输出，应该看到类似以下内容：

```
开始验证设备: {sdkCode: "MI-BAND-SDK-2024", deviceName: "我的小米手环", deviceType: "智能手环", connectionType: "Bluetooth"}
SDK验证结果: true
开始调用后端API...
发送请求到: /spbYq/deviceSdk/addBySdk
请求数据: {sdkCode: "MI-BAND-SDK-2024", deviceName: "我的小米手环"}
```

#### 步骤3：检查网络请求

1. 切换到 "Network"（网络）标签
2. 点击"验证并添加"
3. 查找 `addBySdk` 请求
4. 查看：
   - 请求状态码（应该是200）
   - 请求参数
   - 响应内容

**正常响应示例：**
```json
{
  "code": 1,
  "msg": "设备添加成功",
  "content": {
    "deviceId": 5,
    "deviceName": "我的小米手环",
    "deviceType": "智能手环",
    "deviceBrand": "小米",
    "deviceModel": "MI-BAND-7",
    "deviceSn": "MI-BAND-SDK-2024",
    "connectionType": "Bluetooth",
    "status": "online"
  }
}
```

**错误响应示例：**
```json
{
  "code": 0,
  "msg": "请先登录"
}
```

### 🛠️ 快速测试

在浏览器控制台中直接运行以下代码测试：

```javascript
// 测试SDK验证
$.get('/spbYq/deviceSdk/validate', {sdkCode: 'MI-BAND-SDK-2024'}, function(res) {
  console.log('验证结果:', res);
});

// 测试添加设备
$.post('/spbYq/deviceSdk/addBySdk', {
  sdkCode: 'MI-BAND-SDK-2024',
  deviceName: '测试手环'
}, function(res) {
  console.log('添加结果:', res);
});
```
