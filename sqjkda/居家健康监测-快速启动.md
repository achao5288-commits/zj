## 🔌 API接口列表

所有API都已实现,基础URL: `/spbYq`

### 设备管理 `/healthDevice`
```
GET    /healthDevice/queryByPage      # 分页查询设备
GET    /healthDevice/queryById/{id}   # 查询设备详情
POST   /healthDevice/add              # 添加设备
POST   /healthDevice/edit             # 编辑设备
POST   /healthDevice/deleteById/{id}  # 删除设备
```

### 健康监测 `/healthMonitoring`
```
GET    /healthMonitoring/queryByPage        # 分页查询监测数据
POST   /healthMonitoring/add                # 添加监测数据
GET    /healthMonitoring/statistics/type    # 按类型统计
GET    /healthMonitoring/statistics/date    # 按日期统计
```

### 健康打卡 `/healthCheckin`
```
GET    /healthCheckin/queryByPage    # 分页查询打卡记录
GET    /healthCheckin/today          # 查询今日打卡
POST   /healthCheckin/add            # 添加/更新打卡
```

### 预警通知 `/healthAlert`
```
GET    /healthAlert/queryByPage          # 分页查询预警
GET    /healthAlert/unread/count         # 未读预警数量
GET    /healthAlert/unread               # 未读预警列表
POST   /healthAlert/markAsRead/{id}      # 标记已读
POST   /healthAlert/handle               # 处理预警
```
